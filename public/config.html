Nhập / cập nhật API key

Địa chỉ GỐC của backend phát hiện lừa đảo, KHÔNG kèm đường dẫn (ví dụ: https://scam-detect-xxxx.azurewebsites.net). Server sẽ tự thêm /api/chat.

Key dùng để server gọi backend phát hiện lừa đảo (gửi trong header X-API-Key).

Key bảo vệ trang quản trị và trang cấu hình này (gửi trong header X-Admin-Key tới backend).

Vì đã có ADMIN_API_KEY, bạn phải nhập key hiện tại để được phép thay đổi.

Cấu hình được lưu vào file .env trên máy chủ. Không chia sẻ file này hoặc các key cho người khác.
